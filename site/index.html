Program.cs C# 
var options = new SQLiteOptionsBuilder("books.db")
    .UseMinimumSqliteVersion(SQLiteMinimumVersion.V3_36)
    .Build();

using SQLiteDatabase db = new(options);

var topAuthors = await (
    from b in db.Table<Book>()
    join a in db.Table<Author>() on b.AuthorId equals a.Id
    where b.Price < 30
    group b by a.Name into g
    orderby g.Sum(b => b.Sales) descending
    select new
    {
        Author = g.Key,
        Titles = g.Count(),
        Revenue = g.Sum(b => b.Sales),
    }
).Take(5).ToListAsync();

Translate C# LINQ to SQLite SQL

Filter, join, group and project data with IQueryable. Compare each C# LINQ example with the SQLite query it generates.

C# LINQ query 
var topAuthors = await (
    from b in db.Table<Book>()
    join a in db.Table<Author>()
        on b.AuthorId equals a.Id
    where b.Price < 30
    group b by a.Name into g
    orderby g.Sum(b => b.Sales) descending
    select new
    {
        Author = g.Key,
        Titles = g.Count(),
        Revenue = g.Sum(b => b.Sales),
    }
).Take(5).ToListAsync();

SQL Generated SQLite 
SELECT a0."AuthorName" AS "Author",
       COUNT(*) AS "Titles",
       SUM(b0."BookSales") AS "Revenue"
FROM "Books" AS b0
INNER JOIN "Authors" AS a0
    ON b0."BookAuthorId" = a0."AuthorId"
WHERE b0."BookPrice" < @p0
GROUP BY a0."AuthorName"
ORDER BY SUM(b0."BookSales") DESC
LIMIT @p1;

SQLite features for .NET apps

Query JSON, search text and update rows through one typed C# API.

LINQ to SQLite

Use IQueryable for joins, grouping, subqueries, window functions and common table expressions. The framework translates them to SQLite SQL.

Async SQLite queries

Read, insert, update and delete data with async APIs. Use the same typed tables and LINQ queries throughout your app.

Native AOT support

The framework never generates code at runtime. An optional source generator emits row readers at build time for Native AOT apps.

Full-text and spatial search

Search text with SQLite FTS5 and query spatial data with R-Tree through typed C# APIs.

SQLite JSON and JSONB

Query JSON columns with LINQ. Use JSONB when your SQLite runtime supports it, starting with SQLite 3.45.

Bulk updates and deletes

Use ExecuteUpdate and ExecuteDelete to change matching SQLite rows in one SQL statement.

How LINQ queries become SQLite results

From a C# expression to typed results, with no code generated at runtime.

  1. You write LINQ

    A normal query against a typed table. The C# compiler turns it into an expression tree.

  2. The tree becomes SQL

    The framework walks that expression tree and writes plain SQLite SQL with bound parameters. No IL is emitted.

  3. SQLite returns rows

    The SQL runs and SQLite hands back a row reader.

  4. A materializer fills your objects

    A row reader maps columns to C# objects. Use reflection by default or build-time readers from SQLite.Framework.SourceGenerator for Native AOT.

SQLite ORM questions

Does SQLite.Framework support .NET Native AOT?

Yes. Add SQLite.Framework.SourceGenerator and call UseGeneratedMaterializers to generate row readers at build time. The framework does not generate code at runtime. See the Native AOT setup and trimming guide.

Can I share a SQLite database across threads?

Yes. Create one SQLiteDatabase and share it across the app. Commands take a connection lock automatically. Turn on WAL mode so reads and writes do not block each other. See Multi-threading.

How do I encrypt a SQLite database in C#?

Yes. Use the SQLite.Framework.Cipher package, which ships SQLCipher. Call UseEncryptionKey on the options builder.

Which .NET and SQLite versions are supported?

.NET 8, 9 and 10. It uses the SQLite that ships with your OS by default. You can set a minimum version on the builder or ship a pinned binary with the Bundled package.

Does SQLite.Framework support database migrations?

Yes. A versioned migration runner handles SQLite schema changes. Write hooks (OnAdd and OnUpdate) run before a save for audit and derived values. There is no automatic change tracker, unit of work or lazy loading. See the SQLite migration guide.

How is it different from EF Core or sqlite-net-pcl?

SQLite.Framework translates LINQ joins, grouping and Select projections to SQLite SQL. It supports Native AOT with a source generator and has no automatic change tracker. See Migrating from EF Core and Migrating from sqlite-net-pcl for API differences and setup examples.
